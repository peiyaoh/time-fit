# Security Policy

## Supported versions

Before 1.0, only the latest release on the default branch is supported. Earlier releases are
not supported.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/peiyaoh/time-fit/security/advisories/new). Do not open a public issue. Include the affected package and version, reproducible steps or a proof of concept, the expected impact, and any suggested mitigation or workaround.

The maintainer reviews reports and responds on a best-effort basis; no response-time SLA is
promised.

## Scope

This policy covers the publishable packages: `@time-fit/core`, `@time-fit/storage-prisma`,
and `@time-fit/integrations`. [`contrib/legacy/`](contrib/legacy/README.md) is frozen and out
of scope; its accepted dependency advisories are documented in that README.
